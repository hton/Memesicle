# Privacy Policy / Политика конфиденциальности — Memesicle

---

## English

**Memesicle Privacy Policy**
Effective date: 29.10.2026

Memesicle ("the app") is a local-only tool for storing and quickly inserting GIFs, stickers and emoji. The app has no backend server and does not transmit user data to the developer or any third party.

**What data is processed**
- Images, GIFs and videos the user explicitly imports via Share, a file picker, or a pasted link — stored locally on the device in the app's private storage.
- Tags and metadata (category, favorite status, use count) added by the user — also stored locally only.
- When importing from a link, the app makes a direct HTTP(S) request to the user-supplied address to download the file. This request does not pass through any developer-owned server.

**What the app does not do**
- No analytics, no advertising SDKs, no trackers.
- No account or sign-in required.
- Does not transmit clipboard contents or imported files to any developer server.
- Does not use the Accessibility API and does not read other apps' content.

**Storage and deletion**
All data lives in the app's private storage (`/data/data/com.pdv.memesicle/`) and is fully removed when the app is uninstalled. Android Auto Backup is disabled by the developer (`allowBackup=false`), so the user's library is not automatically copied to the cloud.

**Permissions**
See `permissions.md` in this folder for the full list of requested permissions and their purpose.

**Changes**
If functionality affecting data handling changes, this page will be updated with a new effective date.

Questions about this policy — 369664@gmail.com

## Русский

**Политика конфиденциальности Memesicle**
Дата вступления в силу: 29.10.2026

Memesicle («приложение») разработан как локальный инструмент хранения и быстрой вставки GIF, стикеров и эмодзи. Приложение не имеет серверной части и не передаёт данные пользователя разработчику или третьим лицам.

**Какие данные обрабатываются**
- Изображения, GIF и видео, которые пользователь явно импортирует через «Поделиться», выбор файла или вставку ссылки — хранятся локально на устройстве в приватной папке приложения.
- Теги и метаданные (категория, избранное, счётчик использований), которые пользователь добавляет сам — также хранятся только локально.
- При импорте по ссылке приложение выполняет прямой HTTP(S)-запрос к указанному пользователем адресу для скачивания файла. Этот запрос не проходит через серверы разработчика.

**Чего приложение не делает**
- Не собирает аналитику, не использует рекламные SDK и трекеры.
- Не требует регистрации или аккаунта.
- Не передаёт содержимое буфера обмена или импортированные файлы на сервер разработчика.
- Не использует Accessibility API и не читает содержимое других приложений.

**Хранение и удаление данных**
Все данные хранятся в приватном хранилище приложения (`/data/data/com.pdv.memesicle/`) и удаляются полностью при удалении приложения. Резервное копирование (Android Auto Backup) отключено разработчиком (`allowBackup=false`), поэтому библиотека пользователя не копируется в облако автоматически.

**Разрешения**
Полный список запрашиваемых разрешений и их назначение — см. `permissions.md` в этой папке.

**Изменения политики**
При изменении функциональности, затрагивающей обработку данных, эта страница будет обновлена с указанием новой даты вступления в силу.
