## English

**Memesicle Privacy Policy**
Effective date: 16.11.2026

Memesicle ("the app") is a local-only tool for storing and quickly inserting GIFs, stickers and kaomoji (text emoticons). The app has no backend server and does not transmit user data to the developer or any third party.

**What data is processed**
- Images, GIFs and videos the user explicitly imports via Share, a file picker, or a pasted link — stored locally on the device in the app's private storage.
- Tags and metadata (category, favorite status, use count) and the user's own kaomoji — also stored locally only.
- When importing from a link, the app makes a direct HTTP(S) request to the user-supplied address to download the file. This request does not pass through any developer-owned server.
- When the user taps "Download starter pack", the app downloads a public archive from GitHub (`github.com/hton/Memesicle`). No user data is sent with this request.
- Optionally, if the user grants "Usage access", the app checks which app is currently in the foreground (its package name only) so the floating button is shown only in apps the user has selected. This check happens on the device; the information is not stored or transmitted.

**In-app purchase**
Memesicle Premium is a one-time purchase handled entirely by Google Play. Payment details are processed by Google and are never available to the app or the developer. The app only receives from Google Play whether Premium has been purchased on the user's Google account, and keeps that status locally on the device. Google's handling of payment data is described in the [Google Privacy Policy](https://policies.google.com/privacy).

**What the app does not do**
- No analytics, no advertising SDKs, no trackers.
- No account or sign-in required.
- Does not transmit clipboard contents or imported files to any developer server.
- Does not use the Accessibility API and does not read other apps' content.

**Storage and deletion**
All data lives in the app's private storage (`/data/data/com.pdv.memesicle.app/`) and is fully removed when the app is uninstalled. Android Auto Backup is disabled by the developer (`allowBackup=false`), so the user's library is not automatically copied to the cloud. A purchased Premium remains tied to the user's Google account and can be restored after reinstalling.

**Permissions**
See [`permissions.md`](permissions.md) for the full list of requested permissions and their purpose.

If functionality affecting data handling changes, this page will be updated with a new effective date.

## Русский

**Политика конфиденциальности Memesicle**
Дата вступления в силу: 16.11.2026

Memesicle («приложение») разработан как локальный инструмент хранения и быстрой вставки GIF, стикеров и каомодзи (текстовых смайликов). Приложение не имеет серверной части и не передаёт данные пользователя разработчику или третьим лицам.

**Какие данные обрабатываются**
- Изображения, GIF и видео, которые пользователь явно импортирует через «Поделиться», выбор файла или вставку ссылки — хранятся локально на устройстве в приватной папке приложения.
- Теги и метаданные (категория, избранное, счётчик использований), а также собственные каомодзи пользователя — также хранятся только локально.
- При импорте по ссылке приложение выполняет прямой HTTP(S)-запрос к указанному пользователем адресу для скачивания файла. Этот запрос не проходит через серверы разработчика.
- По нажатию «Скачать стартовый набор» приложение скачивает публичный архив с GitHub (`github.com/hton/Memesicle`). Никакие данные пользователя при этом не передаются.
- Если пользователь по желанию выдаст «Доступ к данным об использовании», приложение проверяет, какое приложение сейчас открыто (только имя его пакета), чтобы показывать плавающую кнопку только в выбранных пользователем приложениях. Проверка выполняется на устройстве, информация не сохраняется и не передаётся.

**Встроенная покупка**
Memesicle Премиум — разовая покупка, которую полностью обрабатывает Google Play. Платёжные данные обрабатывает Google; ни приложению, ни разработчику они недоступны. Приложение получает от Google Play только информацию о том, куплен ли Премиум на Google-аккаунте пользователя, и хранит этот статус локально на устройстве. Обработка платёжных данных Google описана в [Политике конфиденциальности Google](https://policies.google.com/privacy?hl=ru).

**Чего приложение не делает**
- Не собирает аналитику, не использует рекламные SDK и трекеры.
- Не требует регистрации или аккаунта.
- Не передаёт содержимое буфера обмена или импортированные файлы на сервер разработчика.
- Не использует Accessibility API и не читает содержимое других приложений.

**Хранение и удаление данных**
Все данные хранятся в приватном хранилище приложения (`/data/data/com.pdv.memesicle.app/`) и удаляются полностью при удалении приложения. Резервное копирование (Android Auto Backup) отключено разработчиком (`allowBackup=false`), поэтому библиотека пользователя не копируется в облако автоматически. Купленный Премиум привязан к Google-аккаунту пользователя и восстанавливается после переустановки.
